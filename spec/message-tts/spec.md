# Feature Specification: App 端本机 TTS 引擎接入与后端选择（Message TTS Local Engine）

**Created**: 2026-10-29
**Status**: Draft
**Input**: User description: "把文字转语音能力挂载在 App 端；把完整配置后端放在语音设置里面让人可以选择"（用户提供官方 CoreSpeechKit textToSpeech 参考代码）

## Overview

消息朗读功能当前仅支持服务器端 TTS（语音设置中配置的预设/供应商）。本特性在 App 端接入 HarmonyOS 系统本机语音合成引擎（CoreSpeechKit），并在现有"语音设置"页中把它作为可选 TTS 后端与服务器预设并列，用户可自由选择朗读后端并配置本机引擎的完整参数（语速/音调/音量/音色/合成模式）。选择本机引擎后，消息朗读完全在端侧完成，无需服务器参与、不消耗流量、无需任何 API Key。

**现状基线（已存在，不重复建设）**：消息气泡已有朗读按钮（合成中 loading → 播放中停止态 → 播完自动复位，含 Markdown 剥离 `ttsPlainText`）；服务器 TTS 链路（`VoiceService.tts` → 音频字节 → `AudioIOService.playTts` 临时文件 + AVPlayer）；语音设置页（我的 → 语音设置）已有服务器 STT/TTS 预设卡片、配置弹窗与激活切换。本特性复用以上交互与页面骨架，仅新增后端与配置能力。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 语音设置选择本机引擎并配置参数 (Priority: P1)

用户进入"我的 → 语音设置"，在 TTS 区看到新增的"本机引擎"卡片（与服务器预设并列）。点击"设为当前"将其激活为朗读后端；点击"配置/编辑"打开完整参数面板，可调节：语速（0.5-2.0）、音调（0.5-2.0）、音量（0-2）、音色（引擎提供的人声）、合成模式（在线/离线），保存后全局生效并本地持久化。

**Why this priority**: 后端选择与参数配置是使用本机引擎的前置入口，也是本特性区别于现状的核心增量。

**Independent Test**: 在语音设置页找到本机引擎卡片，设为当前并修改语速，验证卡片状态切换与参数保存。

**Acceptance Scenarios**:

1. **Given** 语音设置页, **When** 页面加载完成, **Then** TTS 区显示"本机引擎"卡片，与服务器预设并列，且能看到当前激活的后端标识
2. **Given** 本机引擎卡片, **When** 用户点击"设为当前", **Then** 激活标识移到本机引擎，此状态持久化（重启 App 后仍为本机引擎）
3. **Given** 本机引擎已激活, **When** 用户打开参数面板修改语速并保存, **Then** 参数持久化，下次打开面板显示已保存值
4. **Given** 本机引擎已激活, **When** 用户点击任一服务器 TTS 预设"设为当前", **Then** 后端切回服务器（现有激活逻辑），本机引擎卡片取消激活态

---

### User Story 2 - 本机引擎朗读消息 (Priority: P1)

后端为本机引擎时，用户点击助手消息操作行的朗读按钮，App 调用系统 CoreSpeechKit 在端侧合成并播放语音，全程不请求服务器；朗读中按钮为停止态，再次点击停止；点其他消息的朗读按钮自动切换；播完按钮自动复位。

**Why this priority**: 这是本特性的核心价值——零配置、零流量、无 Key 即可朗读。

**Independent Test**: 激活本机引擎后，在任意会话点击一条已完成助手回复的朗读按钮，验证端侧出声与按钮状态流转。

**Acceptance Scenarios**:

1. **Given** 后端 = 本机引擎、一条已完成助手回复, **When** 点击朗读按钮, **Then** 3 秒内设备出声（端侧合成，无网络请求），按钮变停止态
2. **Given** 本机引擎朗读中, **When** 再次点击该按钮, **Then** 立即停止，按钮复位
3. **Given** 消息 A 朗读中, **When** 点击消息 B 的朗读按钮, **Then** A 停止复位、B 开始朗读
4. **Given** 一条消息朗读中, **When** 播放自然完成, **Then** 按钮自动复位
5. **Given** 后端 = 服务器（现有行为）, **When** 点击朗读按钮, **Then** 走现有服务器 TTS 链路，交互与现状完全一致

---

### User Story 3 - 后端切换、降级与生命周期兜底 (Priority: P2)

朗读进行中切换 TTS 后端立即停止当前朗读；离开聊天页、切换会话、退出应用时停止朗读并释放本机引擎；本机引擎不可用（如部分模拟器无引擎）或合成失败时给出简洁提示，不影响聊天主流程，也不影响继续使用服务器 TTS。

**Why this priority**: 保证多后端并存下状态一致、无"幽灵声音"、异常环境优雅降级。

**Independent Test**: 朗读中切后端/切会话验证声音停止；在无引擎环境点击朗读验证提示。

**Acceptance Scenarios**:

1. **Given** 本机引擎朗读中, **When** 用户在语音设置切换到服务器后端, **Then** 当前朗读立即停止、按钮复位
2. **Given** 朗读中, **When** 用户切换会话或离开聊天页, **Then** 朗读停止
3. **Given** 应用退出或聊天页销毁, **Then** 本机引擎停止并释放，无残留声音
4. **Given** 设备无本机 TTS 引擎或初始化失败, **When** 点击朗读, **Then** 出现简洁提示（如"本机语音引擎不可用"），聊天功能不受影响
5. **Given** 本机合成过程出错, **When** 引擎回调错误, **Then** 按钮复位并提示，不崩溃

---

### Edge Cases

- 朗读文本沿用现有 Markdown 剥离逻辑（代码块→"（代码略）"、去星号/井号等），本机引擎与服务器后端共用同一份纯文本
- 中英文混合消息：本机引擎用 zh-CN 上下文朗读，混排英文按引擎默认发音
- 超长消息：交由本机引擎整体合成，不做客户端截断；引擎报错则走降级提示
- 流式输出中的消息：沿用现状（操作行在流式完成后出现，天然不可提前朗读）
- 新一轮流式回复开始：不打断当前朗读
- 服务器 TTS 未配置且后端 = 服务器：保持现有提示（引导去语音设置）
- 本机引擎参数面板在无引擎设备上仍可设置保存（朗读时才提示不可用）

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 语音设置页 TTS 区 MUST 新增"本机引擎"选项卡片，与服务器预设并列展示，含"设为当前"与"配置"操作及激活态标识
- **FR-002**: 本机引擎参数面板 MUST 提供完整配置：语速 0.5-2.0、音调 0.5-2.0、音量 0-2、音色（引擎支持的人声列表选择）、合成模式（在线/离线），带默认值（1.0/1.0/2/默认人声/默认模式）
- **FR-003**: 本机引擎选择与参数 MUST 为 App 级全局设置，本地持久化，所有会话共用；服务器预设激活仍走现有服务器状态
- **FR-004**: 当前后端 = 本机引擎时，朗读按钮 MUST 使用端侧 CoreSpeechKit 合成播放，MUST NOT 请求服务器
- **FR-005**: 当前后端 = 服务器时，MUST 走现有服务器 TTS 链路，行为与现状一致
- **FR-006**: 后端切换 MUST 立即生效；朗读进行中切换后端 MUST 停止当前朗读并复位按钮
- **FR-007**: 本机引擎朗读 MUST 支持：再次点击停止、切换朗读目标自动停前一条、播完自动复位
- **FR-008**: 离开聊天页、切换会话、应用退出时 MUST 停止本机朗读并释放引擎资源，无残留声音
- **FR-009**: 本机引擎不可用/初始化失败/合成失败 MUST 给一次性简洁提示，MUST NOT 崩溃、MUST NOT 影响聊天与服务器 TTS 功能
- **FR-010**: 朗读文本 MUST 沿用现有 Markdown 剥离逻辑，两后端共用
- **FR-011**: 本机合成启动（点击到出声）在真机上 MUST ≤ 3 秒

### Key Entities *(include if feature involves data)*

- **TTS 后端选择（TtsBackendChoice）**: 当前朗读后端（本机引擎 | 服务器），App 级本地持久化，全局唯一
- **本机引擎配置（LocalTtsConfig）**: 语速、音调、音量、音色、合成模式五项参数，App 级本地持久化
- **本机 TTS 引擎实例**: CoreSpeechKit 合成引擎句柄，懒创建、闲置/离页释放，生命周期与聊天页绑定
- **可朗读文本（SpeakableText）**: 消息内容剥离 Markdown 后的纯文本（现有逻辑复用）

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 激活本机引擎后点击朗读，真机 3 秒内出声且全程无网络请求（可用抓包/飞行模式验证：飞行模式下仍能朗读）
- **SC-002**: 后端选择与参数修改后，重启 App 100% 保持
- **SC-003**: 两种后端下朗读按钮状态流转（合成中/停止态/复位）行为一致，三种停止路径（手动/切换/播完）全部正确复位
- **SC-004**: 无本机引擎的环境（模拟器）点击朗读仅出提示，聊天收发与服务器 TTS 全部正常

## Assumptions

- 真机为支持 CoreSpeechKit 的 HarmonyOS 设备且系统带 TTS 引擎；部分模拟器可能无引擎（走降级提示路径）
- 本机引擎无需任何用户授权权限；CoreSpeechKit 端侧能力不依赖 OctopLink 服务器
- 服务器端与 dashboard 不做任何改动；"本机引擎"不出现在服务器 provider 列表中，纯端侧概念
- 服务器 TTS 的参数 UI（语速等）本版本不扩展，仅本机引擎提供完整参数面板
- 现有朗读按钮位置、图标、合成中 loading 交互保持不变
